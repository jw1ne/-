# 🩺 AI 기반 심전도(ECG) 데이터 분석을 통한 부정맥 판별 시스템 개발
> **한림대학교 소프트웨어 캡스톤 디자인 (팀 이공이공)** > **협력 기업:** ㈜안랩 | **지도 교수:** 안재목 교수님

---

## 📌 개요 (Abstract)
고령화 및 식습관 변화로 인해 심혈관 질환 환자가 증가함에 따라, 일상적인 심전도(ECG) 모니터링의 중요성이 커지고 있습니다. 본 프로젝트는 MIT-BIH 데이터를 기반으로 **Conv1D CNN 모델**을 구축하여 부정맥을 높은 정확도로 판별하고, 사용자가 직접 파일을 업로드해 실시간으로 위험도를 확인할 수 있는 웹 기반 시스템을 제안합니다.

## ✨ 핵심 기능 (Key Features)
1. **ECG 데이터 파이프라인 구축**
   * MIT-BIH 데이터셋에서 환자 데이터를 추출하여 10초 단위 분할 및 정상/부정맥 데이터셋 구축
2. **최적의 AI 모델 선정**
   * 단일 모델에 의존하지 않고 BatchNorm, Deep Layer 등 **5가지 CNN 구조를 비교 평가**하여 Accuracy, F1-score, AUC 측면에서 최적의 후보 선정
3. **사용자 친화적 웹 UI (Streamlit)**
   * CSV, NPY 형태의 새로운 ECG 파일 업로드 기능 지원
   * Plotly를 활용한 실시간 ECG 신호 동적 그래프 시각화
   * 부정맥 가능성을 0~100%의 위험도로 변환하여 직관적인 결과 제공
